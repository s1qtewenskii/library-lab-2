# Лабораторная работа № 2

**Регулярные выражения. Unit-тестирование**  
Прикладное программирование, Python. Вариант № 16: проверка и поиск времени в формате ЧЧ:ММ:СС.

## Запуск

Нужен Python 3.10 или новее. Сторонние библиотеки устанавливать не нужно.
Из папки проекта:

```bash
python main.py
```

В меню можно проверить введенную строку или найти время в текстовом файле.
Для примера введите путь `examples/schedule.txt`: программа найдет пять записей.
Файл должен быть в UTF-8; UTF-8 с BOM тоже поддерживается.
Относительные пути задаются от папки, из которой запущена программа.

## Правила

- Часы: от 00 до 23, минуты и секунды: от 00 до 59.
- Каждая часть содержит ровно две обычные цифры, разделитель — двоеточие.
- При проверке вся строка должна соответствовать формату, пробелы не убираются.
- При поиске время должно быть отделено от букв, цифр, подчеркивания и двоеточия.
- Совпадения выводятся по порядку, повторы сохраняются.

Например, `23:59:59` корректно, а `24:00:00` и `9:00:00` — нет.
Дополнительная секунда `23:59:60` в этом варианте не учитывается.

## Тесты

```bash
python -m unittest discover -s tests -v
```

Проверяются допустимые и ошибочные значения, границы диапазонов,
поиск в тексте и работа с файлами. Тесты не требуют подключения к интернету.

## Файлы

- `time_validator.py` — регулярные выражения и функции проверки и поиска.
- `main.py` — консольное меню и обработка ошибок чтения файла.
- `tests/test_time_validator.py` — unit-тесты.
- `examples/schedule.txt` — пример входного файла.
- `docs/report.md`, `docs/report.pdf` — отчет о работе.
- `docs/defense.md` — краткие ответы на вопросы к защите.
